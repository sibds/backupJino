# Правило для изменяющегося файла в текущей выгрузке

В запросе о различающемся содержимом одного и того же пути добавлен флажок «Применять к следующим изменениям этого файла в текущем задании». Он выключен по умолчанию. Выбранное действие сохраняется в задании и применяется к последующим версиям этого файла, включая продолжение после обрыва или перезапуска исполнителя. Новое задание не наследует правило.

Правило не распространяется на другие пути, конфликты регистра и смену типа объекта. Точный ответ для конкретной версии имеет приоритет над правилом. Проверки источника, SHA-256 и сохранение прежнего содержимого при обновлении остаются обязательными.

Отвеченные и пропущенные запросы убраны из блока выбора карточки; события остаются в журнале. Общие уведомления также учитывают правило задания. Запись ответа не означает, что новая версия уже скачана или проверена.

Протокол применения: `.state/session-file-rules-deployment.json`.

Проверки: 553 passed, 1 skipped; 39 JS-тестов. Проверены последовательные изменения файла с сохранением исходных байтов, отсутствие распространения правила на другой путь, сохранение правила через API, скрытие отвеченных карточек и уведомлений.
