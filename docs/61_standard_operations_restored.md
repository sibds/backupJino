# Возврат к штатной работе

18 ноября 2026 года пользователь отменил временное ограничение двумя приоритетными серверами и поручил продолжить ранее приостановленные задания для всех доступных серверов.

Через API работающей панели возобновлены задания доступных записей, сохранены прежние ключи и части. Перезапуска исполнителя не было. Восстановлены 40 ранее включённых правил с прежними индивидуальными интервалами и пять групп отдельных расписаний БД. Новые интервалы не назначались. Отложенные версии сохраняют зависимость от первой полной копии.

Итоговая проверка: 21 доступный сервер, 35 заблокированных записей. Для каждой доступной записи и каждого вида работы (файлы/БД) есть поставленное задание либо ранее завершённая копия соответствующего полного состава. Доступных записей с заданиями в PAUSED не осталось. Это не подтверждение завершения резервных копий всех серверов.

Во время контрольного замера работали шесть файловых заданий, включая отдельную проверку; 32 задания находились в очереди, семь ожидали допуска входа в Jino. Планировщик сохраняет ограничения на подключения и параллельную работу. CAPTCHA/MFA и блокировки не сбрасывались. Четыре задания заблокированных записей остались приостановленными.

При первоначальном запуске операционного скрипта для строки 7 была ошибочно сравнена общая revision настроек (2) с revision задания, содержащей версию привязки (1). Проверка исправлена на binding_revision (1); отложенное задание возвращено в план. Созданное из-за этой ошибки лишнее БД-задание остановлено до первого входа/старта, без изменения готовых дампов и прежних заданий. Производственный код не менялся.

Основной протокол: `.state/standard-operations-restoration.json`, итоговые проверки — поле `verification`. Атомарное восстановление правил: `.state/standard-rules-restoration.json`. Исправление операционной проверки: `.state/standard-binding-correction.json`.
