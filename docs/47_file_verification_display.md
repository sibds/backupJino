# Передача и проверка файлов в карточке

Карточка сервера теперь отдельно показывает завершение передачи и текущую проверку: «Проверено N из M · K ожидают проверки». Эти сведения находятся в сводке, на вкладке файлов и в правом блоке страницы «Серверы». На вкладке файлов полоса передачи подписана отдельно от полосы проверки. При отсутствии активного файла после передачи больше не предлагается ждать её начала.

Число проверенных файлов берётся из `progress.processed_files` текущего задания, а не из `verified_files`: последнее поле отражает готовые записи checkpoint, включая прошлые проходы и другие сохранённые файлы. Поэтому прежнее сочетание «найдено 7 673, проверено 7 902» заменено на текущие 1 261 из 7 673 и очередь 6 412 в регрессионном примере. Общая метрика checkpoint подписана «Файлов сохранено».

Знаменатель появляется только после полной инвентаризации. Для старых заданий без текущего счётчика выводится неизвестное значение, а не историческое число. Успешный результат использует итоговый `files_count`, учитывающий дедупликацию. `PARTIAL`, ошибки и остановка не получают подпись успешной проверки. Ожидание очереди проверки и ручная пауза обозначаются отдельно. При неизменных значениях содержимое блока не пересоздаётся при каждом опросе.

Формула общей полосы в таблице файлов/БД этой доработкой не менялась — [23](23_server_table_progress.md). Исполнитель, API, расписания и сохранённые копии не изменялись; достаточно обновить страницу.

Проверки: **27 JS-тестов**, включая пять новых сценариев; **14 тестов панели**. `scripts/check_file_verification_ui.py` использует только синтетический сервер, допускает только GET, проверяет три места отображения и отдельные полосы на 1440/1000/800/390 px. Ошибок страницы и изменяющих запросов нет.
